# 个人助手测试计划

版本：v0.2（已含用户决策 D1–D8）
总则：
- 测试不依赖真实付费 LLM/Embedding 调用（一律 Mock）；不依赖真实外网（适配器层注入 fixture/Mock）。
- **测试不触碰唯一真实生产数据**：所有测试用隔离副本或临时库（conftest 统一提供），并设"数据隔离守卫"用例断言测试运行期间真实聊天库路径零写入（PRD §2.6）。
- **禁止删除失败测试或绕过业务逻辑制造通过**。

## 1. 工具链

- 后端：pytest + pytest-asyncio + httpx(AsyncClient) + respx(httpx Mock) + 临时目录 SQLite/Chroma fixture（conftest 统一提供）。
- 前端：Vitest + React Testing Library（关键组件/页面逻辑）。
- 端到端：阶段 6 以手工脚本为主（清单见 §5），可选 Playwright 固化。
- LLM Mock：fake ChatOpenAI（langchain 可注入），固定返回 JSON；Embedding Mock 返回确定性向量。

## 4. 异常场景测试清单

- 外部 API 不可用 / 网络超时 / 限流（Mock 抛错 → 前端可读错误 + 任务 failed 有因）
- WeChatDataAnalysis 启动失败 / 启动后 API 不就绪（超时上限、明确提示）
- SQLite 库被占用（WAL 下并发读；写锁冲突重试后报错不崩）
- Chroma 写入失败（索引构建失败不影响已有索引——现有 incremental 设计保持）
- LLM 请求失败/输出截断（现有 summarizer 重试路径保持；任务层兜底）
- 同步重复执行/双击（任务重复提交保护 + 主键幂等 + 游标已提交双保险）
- 清理中途进程终止（执行器 kill 后重启续跑，无重复删除、无半删状态残留）
- 周日未启动程序（启动后恰好生成一次候选；跳过不删除）
- 用户取消删除 / 只勾部分（仅勾选项被删，其余原样）
- 非授权删除（直接调用执行接口无 confirmed run → 409；构造自动删除入口不存在）
- 隔离违例（测试代码误写真实库路径 → 守卫测试拦截报错）

## 5. 端到端验收脚本（阶段 6 执行）

1. 双击桌面快捷方式 → 浏览器自动打开首页。
2. 新建每日计划 → 刷新页面 → 再重启服务 → 数据仍在。
3. 添加书籍、上传笔记 → 点击在线查看；改状态为"已读" → 重启后保持。
4. 打开技术资讯导航 → 各网站入口在新标签页正常打开；首页与资讯页 TOP 10 内容一致，点击标题展开摘要、查看原文跳转正确；点刷新后榜单更新。
5. 同步微信聊天（真实环境）→ 在对话框输入总结请求并点击快捷按钮 → 查看报告；重复同步 → 消息数不翻倍。
6. 审核页：默认无预选 → 勾选部分 → 二次确认 → 删除 → 三库抽查一致、报告保留、审计正确 → 跳过项原样保留。

（原第 7 条"备份→删除→恢复"随 D1 移除；涉及真实数据的所有演练按 PRD §2.6 先获批准。）

每条脚本记录：前置条件、操作步骤、期望结果、实际结果、截图/日志归档。

## 6. 覆盖率与质量门槛（建议）

- 服务层与状态机行覆盖率 ≥ 80%；适配器分支覆盖正常/超时/失败三态。
- 阶段出口标准：该阶段测试全绿；无 skip 且无 xfail 未解释项。
