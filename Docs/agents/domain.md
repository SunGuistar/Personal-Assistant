# Domain Docs

## Before exploring, read these

- 涉及今日晨报时，先读 [晨报开发规范](../../app/morning_report/AGENTS.md) 和 [晨报术语表](../../app/morning_report/GLOSSARY.md)。
- 阅读 [仓库 ADR](../ADR/) 中与当前任务相关的决策。
- 晨报业务范围、已确认行为和验收条件沿用 [GOALS](../../app/morning_report/GOALS.md) 与 [Product Specs 索引](../../app/morning_report/docs/product-specs/index.md)。

## File structure

本仓库沿用现有领域文档布局。晨报术语表位于 `app/morning_report/GLOSSARY.md`，仓库级 ADR 位于 `Docs/ADR/`。领域文档按项目现有规范维护。

## Use the glossary's vocabulary

在 Issue、Spec、设计讨论和测试中使用术语表定义的词汇。发现术语含义不清或缺少定义时，交由 `domain-modeling` 澄清。

## Flag ADR conflicts

拟议行为与现有 ADR 冲突时，指出相应 ADR、冲突点以及是否需要重新讨论。
