# 开发计划（Development Plan）

各阶段需要实现的功能规划。本文档只回答"做哪些功能"，不承担进度追踪职责（开发历史由 Git 记录）；需求规则见 `PRD.md`，技术设计见 `Architecture.md`。

阶段顺序：0 审查设计 → 1 基础设施 → 2 计划/阅读 → 3 微信集成 → 4 资讯中心 → 5 清理审核 → 6 验收。

## 阶段 0：代码审查与设计

- 现有项目审查；PRD/架构/开发规范文档产出；用户决策 D1–D8 确定。

## 阶段 1：后端基础设施 + 前端框架 + Windows 启动器

- FastAPI 应用装配：统一错误格式、隐私白名单日志、健康检查
- SQLAlchemy + Alembic 初始化；任务框架（状态机 + 同 kind 防重）；token_usage 埋点；会话表
- React + TS + Vite + Tailwind + shadcn/ui + TanStack Query 骨架与页面路由
- Windows 启动器：双击启动服务并打开浏览器
- pytest 骨架 + conftest（临时库、数据隔离守卫）；requirements 裁剪

## 阶段 2：计划管理 + 阅读管理

- 长期计划/每日任务 CRUD、move（溯源不复制）、排序、未完成跨日延续
- 书籍 CRUD、阅读状态、状态筛选；笔记上传/预览/删除（类型/大小/文件头校验，防路径穿越）
- 有笔记书籍禁止删除（后端 409）
- 前端计划页、阅读页

## 阶段 3：微信聊天助手集成

- 回归基线测试（Mock LLM/Embedding）；目录迁移至 `app/wechat_agent/`（D3）
- 重建 normalize_snapshot.py 并与历史库对拍一致；多群适配（按 chat_id 过滤）
- 同步服务：重叠窗口 + 稳定 ID 幂等 + 游标后置提交 + 对账补录 + 增量索引
- Agent 服务化与前端微信页：SSE 流式问答、预置快捷输入、总结经 Agent 单通道（D2）、报告卡片、一键同步

## 阶段 4：技术资讯（近期热门 TOP 10 + 外部导航）

- 适配器/去重/确定性评分链路（HN + 6 个 RSS/Atom 源）；TOP 10 排名（24h 优先/72h 回退/单源上限/稳定排序）与榜单 API
- 前端首页整版 TOP 10 + 资讯页（刷新、失败提示、外部导航）
- 缓存 30 分钟 + 后台刷新 + 单源失败隔离 + 失败保留旧缓存

## 阶段 5：周日人工审核清理（D4）

- cleanup 模块：候选生成（周日/启动补生成、跨周去重）、审核 API、三层删除状态机、Chroma chunk 局部重建与 rag_state 维护、审计、非授权删除防护
- 前端审核页（默认不预选、二次确认、跳过保留）与首页待清理提醒
- 范围仅微信聊天数据；新闻数据不参与清理

## 阶段 6：端到端验收

- PRD 关键端到端验收逐条执行（含真实微信同步与总结、性能冒烟）
- 真实环境清理审核演练（阶段 5 完成后；不可逆操作按 PRD 数据安全规范先获批准）

## 两轮功能优化（2026-11）

- 计划/任务重要置顶与手动排序；长期计划标记完成与历史视图；每日任务历史；TOP 10 中文标题/摘要批量翻译与缓存
- 每日任务统一排序（今日与逾期自由穿插）；计划与任务彻底独立（移除 plan_id）；任务历史只读；长期计划具体目标；书籍重要标记；PC 三栏工作台（右栏重要信息 + 随手备忘）

## 后续规划（V2.0，未经批准不排入当前开发）

- 移动端支持（形态待评估：PWA / 手机浏览器访问 / 独立客户端）
- 备份与恢复系统（覆盖 hub.db + 聊天两库 + Chroma + 笔记附件 + 配置）
- 重复启动处理
