# 今日晨报模块

目的：提供信息，总结我的昨日，给出建议

注意：全面是不可能，所以重点在于热点和兴趣匹配

功能：

- 隔离开发
- 整体资讯内容卡在5-10min(待讨论)

- 中文
- 报告格式化
- 加入deepseek api，今日晨报用deepseek api
  - 只允许低峰时段使用，高峰时段使用dashscope
  - 用deepseeK v4.1 falsh 1017
- 添加大模型token消耗报告，包括总次数，总token消耗，总价格，单次缓存命中数，单次缓存未命中数，单次缓存命中率，单次token消耗，单次价格
- 添加我的喜好分析落库（要memory）

- 语音播报（V2.0）
  - 播报晨报全部内容
  - 导入时间模型：时间，今日天气（配天气图标），日期，地点，温度（V2.0）
