# 基于 Agent 的今日晨报模块 V1.0

一个具备个人记忆、信息筛选、历史回顾和个性化建议能力的 AI 晨报 Agent

- 外部信息： 从海量资讯中发现真正重要、与你兴趣相关的内容。
- 内部信息： 从个人助手已有数据中总结昨天做了什么、哪些事情值得关注。
- Agent 决策： 结合个人记忆，将外部信息和内部进展关联起来，给出有依据、可执行的建议。

## 一、技术决策

| Agent 架构              | RAG                    |
| ----------------------- | ---------------------- |
| 单 Agent + 确定性工作流 | V1.0 暂不引入          |
| **资讯采集**            | **个人记忆**           |
| 后台定时落库            | 结构化持久化记忆       |
| **主模型**              | 备用模型（开发阶段用） |
| DeepSeek Flash          | DashScope              |
| **生成目标**            | **内容长度**           |
| 60 秒内完成             | 默认阅读约 5 分钟      |

## 二、技术选型

#### 1.AIHOT可以直接接入

AIHOT 已提供 REST API、RSS、MCP、Agent Skill 四种接入方式，其中 REST API 支持匿名读取，不需要 API Key。

其热点功能已经具备：

- 多个独立信源合并为同一热点事件。
- 热度分值、24 小时趋势和多信源信息。
- 热点 Top 10、日报、精选内容和事件时间线。

#### 2.模型选择

开发完成后固定上午8点用DeepSeek-V4.1-Flash-1017自动生成，开发阶段以及开发完成后手动生成则用dashscope，因为我接入的是dashscope免费模型。
