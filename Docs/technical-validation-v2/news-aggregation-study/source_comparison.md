# 候选来源逐源实测对比（国内与国际）

> 测试日期：2026-11-10（Asia/Shanghai）；执行机器：Windows，Conda `agent`（Python 3.13.18），本机直连国内网络、无代理。
> 证据：`results/*.json`（每次请求的状态码/耗时/字段）、`fixtures/*`（原始响应）、`api_tests/*.py`（可复跑脚本）。
> 上一轮（T1–T22，2026-11-08/09）已有结论直接复用并标注，不重复测试。

## 1. 国内候选源

### 1.1 热摸爽 remoshuang.com —— 实测可用（有条件）

**连通性**：首页、`/feed.xml`、`/feed/{finance,tech,rising}.xml`、`/daily/<日期>.md`、`/hot/<日期>.md`、`/sitemap.md`、`/llms.txt`、`/agents` 全部 200。多时点调用稳定（13:34–14:00 共 20+ 次请求，平均 <1s）。

**官方机器可读入口（/agents 页明示）**：
| 入口 | 内容 | 关键属性 |
|---|---|---|
| `/daily/<YYYY-MM-DD>.md` | 每日 TOP 30 早报（人工审核），含来源链接、平台数、分类、AI 摘要 | 统计周期为**北京时间 05:00–次日 05:00**，发布时间约 05:2x–05:3x |
| `/hot/<YYYY-MM-DD>.md` | 每天 05:00 冻结的 TOP 20 热点快照（final，永不变） | 覆盖“过去 24 小时”热度，**冻结于 05:00** |
| `/feed.xml` 等 RSS | 热点事件 feed，30 条，带短摘要 | **全部条目 published 时间相同**（feed 生成时间），无逐条原始发布时间 |
| 事件页 `/event/<id>` | 事件聚合：sources（originalUrl+capturedAt）、timeline、热度 | 只有抓取时间 capturedAt，**无原始发布时间** |
| `/api/hot` | 372 个榜单 6207 条（含新闻类 12 榜：腾讯/澎湃/头条/新华网/人民网/人民日报等） | **官方声明 /api/* 是站内自用接口、robots 禁止、字段随时会变，禁止依赖** |

**内容构成**：跨平台热榜聚合 + RSS 新闻源（新华网、澎湃、头条、网易、人民网、人民日报、南方周末等）+ 外国媒体（含纽约时报中文网等）。实测 372 源中 369 活跃。

**对固定窗口（08:00–08:00）的适配性**：
- 早报/快照的统计周期是 **05:00–05:00**，与晨报窗口错开 3 小时：05:00 冻结的快照**不含 05:00–08:00 的当日新闻**，且包含 05:00–08:00（前一天）窗口外内容。
- 条目无原始发布时间字段 → **无法按 08:00 边界精确过滤**；只能按内容中提及的日期+原站链接日期粗判，或接受 05:00 对齐（偏离产品定义 3 小时）。
- 回溯能力好：`/daily/2026-11-09.md` 等历史日期可访问（sitemap 列出 10-12 以来的全部日期）；08:00 当次失败、稍后重试不会丢早期内容（冻结快照不变）。

**覆盖特征（实测）**：偏热点/社交平台话题（王楚钦、遗产罗生门等），公共硬新闻有新华网/澎湃源支撑（太原火灾、APEC/伊朗、油价）。**热度≠重要性**：财经政策类（人民币清算行试点、统计局机构调整）在 TOP 30 中缺席。单日样本（11-09 08:00–11-10 08:00）参考事件命中 2/4 国内、4/5 国际（见 coverage_analysis.md）。

**授权**（/copyright、/agents）：第三方内容权利归原作者/平台；摘要为 AI 重组的简短事实表达，须标注来源并回溯原站核查；要求引用时给原始链接；有删除/更正通道；未禁止个人自动化读取，但 /api 禁止、>40 页/分钟记为突发抓取。

### 1.2 中国新闻网（chinanews.com.cn）—— RSS 形态不可用，按日归档页可用

- **RSS `scroll-news.xml`**：200，30 条，但实测 13:37 与 13:40 两次抓取内容完全一致（缓存稳定），条目时间跨度仅 **约 1.5 小时**（04:03–05:29 UTC）。**单次 08:00 查询只能拿到最近 1–2 小时，无法覆盖 24 小时窗口**。分类 RSS（gn/sh/cj/yaowen）404；`world.xml`（国际）可用，30 条约覆盖最近 8 小时，11/30 条落在测试窗口内。
- **按日归档页 `https://www.chinanews.com.cn/scroll-news/2026/1109/news.shtml`**：200，解析出 **478 条带精确到分钟时间戳的条目**（05:47–23:02）。这是 HTML 抓取（非官方 API），需自行解析，页面结构变化即失效；但对“每天 08:00 一次性取齐 24 小时窗口”**天然适配**：取两天归档页（前一日+当日），按 08:00 边界过滤即可，**支持精确时间过滤**。
- 字段：标题+发布时间+链接+短摘要；无正文（需回溯原站，而本机 news.cn 等部分原站不可达）。
- 授权：robots.txt 对大部分路径 Disallow（RSS 实测可达）；无公开 API 条款，自动化抓归档页**需进一步核实**；作为个人内部使用风险低，但不得对外再分发。

### 1.3 聚合数据（juhe.cn）—— BLOCKED（需 Key），“每日简报 API”未证实存在

- `v.juhe.cn/toutiao/index` 无 Key 调用返回 `{"resultcode":"101","error_code":10001}`——**确认服务在线、必须 Key**。
- 公开文档存在（头条新闻 API：国内/国际/体育/科技等分类，更新 5–30 分钟）。未找到名为“每日简报”的独立 API；最接近的是头条新闻 API（`type=guoji` 含国际）。
- 免费额度（历史上为 100 次/天/接口）需在注册后核实；**本轮不注册、不购买，真实调用标记 BLOCKED**。
- 判断：即使可用，它本质是又一个中转聚合源（无原文、无自主时间窗口参数能力未证实），价值低于直接抓中新网归档；**不建议作为依赖源**，可作为将来人工注册后的辅助源。

### 1.4 GDELT v2 —— 复用 T2 结论 + 本轮补测

- 复用 T2/net_round3（2026-11-09）：中文 48h 查询 200、20+ 条、字段 domain/language/seendate/url/title，无正文、无 Key。
- 本轮补测：精确 `startdatetime/enddatetime` 窗口查询与滚动 `timespan` 的语义、429 限流行为、作为**国际**源的用途（见 2.2）。
- 注意：seendate 是 GDELT 标注的时间（近似发布时间），且单次返回上限 75 条（窗口内中文新闻量远大于 75 时按 hybridrel 排序截断）——**数量多≠覆盖好**，且 429 频繁，需限速。

## 2. 国际候选源

### 2.1 GNews API —— 文档确认可用，免费层对本场景有硬伤

- 本机 `gnews.io/api/v4/top-headlines`（无 Key）返回 400 `No API key was sent`，**端点可达、强制 Key**。
- 官方及多来源文档（2026-08~11）：免费层 100 次/天、每次最多 10 篇、**12 小时延迟**、30 天历史、仅限非商业、CORS 限 localhost；付费 €99.99/月起取消延迟。字段：title/description/url/image/publishedAt/source；**正文截断**（expand=content 需付费）。
- 对本任务的决定性问题：**免费层 12 小时延迟意味着每天 08:00 查询拿不到 20:00–08:00 的最新重大新闻**（约占窗口 1/3），除非购买付费套餐。无 Key 不伪造数据，真实调用标记 BLOCKED。
- 结论：在“不购买套餐”约束下，GNews 免费层**不适合**作为国际每日聚合主源；若用户愿意注册免费 Key，可降级为补充源（延迟需明示）。

### 2.2 GDELT v2（国际）—— 本轮重点补测

- 英文 48h 查询实测 429（限流严格）；窗口精确查询结果见 `results/gdelt_window.json`。
- 优势：免费无 Key、可精确时间过滤、多语言多来源（适合国际）、授权宽松（[GDELT 条款](https://www.gdeltproject.org/about.html#termsofuse)：免费、可商用，需署名 GDELT + 链接）。
- 劣势：无正文无摘要（仅标题）；标题噪声大、同一事件多语言重复多；**无重要性排序**（hybridrel 是相关度排序）；需要自建事件聚合与重要性筛选；中文源的覆盖面与“重大性”参差。
- 判断：作为国际新闻**补充源**（发现+回溯时间）合格，单独承担“每日 08:00 国际重大新闻”不合格。

### 2.3 BBC 等国际 RSS —— 仍不可达（网络出口问题，非技术不可行）

- 复测（2026-11-10 13:36）：`feeds.bbci.co.uk/news/world/rss.xml` 与 `/news/rss.xml` 均 ConnectionError（与 T3 相同，getaddrinfo/连接层失败，DNS 层面不通）。CNN、AlJazeera 2026-11-09 已测失败，本轮未重复。
- 未修改任何代理/网络配置（按任务约束）。
- 结论：在解决网络出口前，**不可作为依赖源**；其价值（原始权威英文报道）仅在代理就绪后评估。D01 已记录的“国际=另案 D02”状态维持。

### 2.4 聚合数据（国际）—— 同 1.3，BLOCKED

`type=guoji` 理论上含国际分类，但需 Key 未注册，无法验证覆盖与原文链接质量；**不因为提供中文摘要就默认可信**。
