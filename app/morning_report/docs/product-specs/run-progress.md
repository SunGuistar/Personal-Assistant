# 任务进度与停止

## 目的与范围

用户和调用方能区分任务已提交、正在处理、部分缺失、停止和完成，并能理解失败原因。对应 GOALS.md 的「控制与回看」、运行可观测性与恢复要求。业务触发和发布规则见[生成规格](report-generation.md)。

## 场景与规则

- **A 任务概况。** 提交后通过任务 ID 跟踪进度。进度应反映已完成、进行中、待处理及复用的工作。采集缺失有警告与原因。长期未更新提示与实际失败分开。
- **A 停止与互斥。** 生成任务遵循互斥规则。用户可停止指定任务，界面应区分请求停止和确认停止。停止保留已完成的阶段记录与已有历史，未完成报告不应作为成功结果发布。
- **A 异常。** 来源、模型、取消和进程中断须有可观察的状态或明确的降级结果。故障信息和诊断中保护密钥、个人内容和完整模型消息。保留已发布结果。重启及重新提交行为见下文 V3 规则。

## 输入输出与状态

**B 已确认的 V3 展示。** 没有可发布内容时，进度显示「未发布 · 暂无可发布内容」。若伴随采集或分析失败，保留各阶段的实际结果及原因。用户可据此区分正常无内容和运行故障。

**B 停止、换日与重启。**

- 以正式发布为停止操作的分界。请求已收到时显示「正在停止」。发布前确认停止的任务不产生新版本。已经正式发布时，停止请求返回实际发布结果。
- 停止操作不承诺固定的等待秒数。模型请求遵守仓库通用的超时和有限重试规则；超时等运行结果应可见，任务收敛后解除生成占用。
- 个人助手服务仍在运行时，切换页面或关闭浏览器标签页只结束查看，生成任务继续运行。返回晨报时恢复原任务的评估档位、进度或已结束结果。提交回执丢失的处理见[生成规格](report-generation.md)。
- 已有生成任务占用入口时，另一标签页独立发起生成只提示冲突，不自动切换到已有任务，也不改变已有任务的评估档位。
- 今日与昨日在北京时间 24:00（次日 00:00）切换。已接受的任务跨过午夜仍可完成，进度继续显示该任务和原报告日，用户仍可停止。它结束前保持生成互斥，页面提示当前占用。发布结果归属原报告日，详见[生成规格](report-generation.md)。
- 应用重启时，先核对未结束任务是否已有正式发布版本。已发布的任务按实际发布结果收敛。未发布且仍处于等待、执行或停止中的任务显示「运行中断」，解除生成占用，等待用户手动发起当前报告日的生成。

**B V3 目标契约。**

| 操作或结果 | 调用方可观察的语义 |
| --- | --- |
| 读取任务、活动任务和进度更新 | 可凭任务标识查询。重新打开页面或恢复连接时可读到已有进度或结果，跨日活动任务仍可发现。未知任务明确报错；没有任务与读取失败可区分。 |
| 等待、执行、停止中 | 任务仍占用生成入口。可读取任务标识、报告日、锁定的评估档位及阶段进度，区分新执行、复用和警告。长期没有更新可提示，并与失败区分。 |
| 已发布 | 进度可关联已发布版本，并保留阶段缺口或警告。 |
| 未发布、失败、已停止、运行中断 | 调用方可以区分对应结果和已知原因。未发布的任务没有新版本；终态解除生成占用。既有发布版本仍保留。 |
| 停止指定任务 | 反馈停止已请求或任务已有的实际结果。重复停止可读取原任务状态；未知任务明确报错。用户取消停止确认时不发送停止请求。 |
| 查看运行诊断及用量 | 可按任务查看非敏感的阶段结果、失败原因及已有模型用量。无用量记录时显示空明细和零汇总。 |

**C V2 对照。** 现行 `/progress/active` 默认仅查当日；进度接口按现有任务枚举和事件流工作，启动恢复只覆盖等待和执行中的任务。字段、状态枚举及事件流兼容留待设计。诊断只提供必要的非敏感信息。

## 验收

- 分别在正式发布前确认停止、发布后发出停止请求，核对终态与版本是否存在一致。
- 生成跨过午夜后刷新页面，验证仍能看到原任务及其报告日、可停止，并能识别当前生成入口被占用的原因。
- 生成期间切页或关闭浏览器标签页，分别在原任务进行中及结束后返回，核对档位、进度或任务结果可恢复。
- 在另一个标签页用不同评估档位独立提交，核对只提示冲突，原任务档位不变。
- 模拟重启前遗留等待中、执行中、停止中任务，以及已发布但尚未记录终态的任务。核对结果按发布事实收敛，未发布任务解除占用，重启不重新发起生成。

- 提交生成后可用 ID 读到同一任务；刷新页面或恢复连接后能查到最新状态。空状态、未开始、复用和告警可辨。
- 在已有活动生成时再次提交生成，观察明确冲突。重复停止、自然完成竞态或未知任务均可区分，并核对现有历史不受影响。
- 模拟来源和模型故障、进程中断及长时间无更新，检查状态、原因及隐私保护。按获准的恢复规则验证重新提交后可观察到新任务，不将已有历史误认为本次产出。
