# 历史晨报与新闻收藏

## 目的与范围

让用户稳定查阅已发布报告并管理想继续关注的新闻。对应 GOALS.md 的「控制与回看」。生成动作及发布前边界见[生成规格](report-generation.md)。

## 场景与规则

- **A 晨报与历史。** 页面提供「晨报正文」「历史晨报」「收藏新闻」同级入口。历史按报告日展示最新已发布版本。失败或停止的运行不替代成功版本。旧版本及其已保存内容继续保留，生成新版本不自动删除旧数据，也不跨日覆盖更新日期的默认晨报。
- **A 收藏。** 在正文或历史报告中设置新闻星标，收藏列表汇总已收藏的资讯条目。取消收藏保留资讯、报告快照、备注和重点；再次收藏可恢复备注及重点。
- **A 备注与重点。** 收藏可编辑备注和独立重点，标题与类别只读。红色五角星标记重点并置顶。取消重点仍保留收藏。备注和重点状态可持久读取，备注不进入模型输入或日志正文。
- **B 无来源链接的收藏。** 已收录但无有效链接的资讯可收藏、编辑备注和设置重点。收藏页显示标题、已有摘要和「暂无来源链接」。
- **B 资讯收藏不去重。** V3 收藏不按标题、链接或内容合并资讯。独立收录的条目分别保留收藏、备注及重点。使用同一条已取得资讯的速览、正文或多个报告版本，共用该条目的收藏、备注及重点状态。
- **B 旧收藏拆分（Q88、Q90）。** 原先共用一个收藏的独立收录条目拆分展示。每条分别继承旧收藏状态、备注和重点。拆分后，取消收藏、修改备注或切换重点只影响对应条目。旧报告仍引用原收录条目，正文和版本继续保留；复用同一条目时仍共享该条目的状态。
- **B 当日正文。** 正文显示北京时间当日最新已发布版本。当日尚无发布时，显示「今日尚未发布」及生成入口，较早日期的报告由「历史晨报」查看。当日首次发布后正文展示该报告。
- **B 版本标识。** 页面使用报告日和版本号标识报告，移除「主报告」文字及对应标记。日内版本与历史数据继续保留，历史仍每个报告日展示最新已发布版本。
- **B 最新版本选择。** 即使同日新发布版本含有带事实错误提示的建议，正文及该日历史条目仍展示最新已发布版本。较早版本保留，问题按[今日建议规则](personal-review.md)标注。
- **B Markdown 下载。** 历史下载包含所选版本已展示的正文、依据摘要、来源链接和评估原因，包括页面上需展开才能查看的内容。历史版本按已发布内容下载，缺失的旧版依据不以当前记录补写。
- **A 历史兼容。** 缺少可关联资讯条目的旧正文仍可读、可下载，相关内容无法标记收藏。

## 输入输出与异常

**B V3 目标契约。**

| 接口 | 输入与返回 |
| --- | --- |
| `GET /report` | 可读取指定报告日的最新已发布版本，或按报告日和版本号读取指定版本。返回报告标识、日期、版本号、标题、正文及可用的结构化内容。当天没有已发布版本时，正文入口可区分未发布和查询失败；指定版本不存在时明确报错。 |
| `GET /history` | 返回 `items`，按日期倒序，每日一条最新已发布版本摘要。无报告时为空列表。 |
| `GET /report/{version_id}/news` | 返回版本关联的资讯条目及其当前收藏状态。无关联时可为空，版本不存在时明确报错。 |
| `PATCH /news/{news_id}/importance` | 以严格布尔值更新指定条目的收藏，返回更新后的条目。找不到条目时明确报错。 |
| `GET /favorites`、`PATCH /favorites/{news_id}` | 列表中每项含新闻标识、标题、类别、链接、收藏状态、`note`、`is_highlighted`。修改仅接收可选字符串 `note`（空串清空）和可选严格布尔 `is_highlighted`，未传字段保持原值。未知字段或类型错误返回校验错误，新闻不存在或未收藏时返回 404。 |

收藏加载或保存失败应显示失败结果，以服务端确认的状态为准。空列表与加载失败应可区分。历史兼容展示允许旧报告缺少新结构，用户收藏操作不改写原报告正文。

**C V2 对照。** 无日期查询当前可返回全局最新报告，报告带「主报告」标记，收藏按内容键关联。旧字段兼容与既有长度限制的表达留待接口设计。

## 验收

- 同一天包含多个已发布版本及一个失败运行时，历史只列该日最新已发布版本，按旧日期和版本号仍可查到历史正文。页面展示报告日和版本号。
- 前一日已有报告而当日未发布时，正文显示当日空状态，前一日报告仍可从历史打开。当日发布后正文展示当日最新版本。
- 分别收藏独立收录但链接或标题相同的资讯，收藏页分别展示。编辑其中一条的备注、切换重点并刷新，观察对应条目的备注和置顶状态。取消重点仍保留收藏。
- 收藏无有效来源链接的资讯，核对收藏页的内容与来源提示，并验证备注及重点可保存和读回。
- 分别收藏两个来源发布的无链接同名资讯，验证编辑备注或重点只影响对应资讯。
- 收藏 v1 的一条资讯并添加备注，v2 复用同一条资讯时仍显示同一收藏状态、备注和重点。另一次独立收录即使标题和链接相同，也有独立状态。
- 构造三个旧资讯条目共用一份收藏、备注和重点的历史数据。升级后验证三条分别展示，初始备注和重点一致；修改或取消其中一条后，另外两条的状态保持原值，旧报告仍可读取。
- 下载含评估标记的历史版本，核对 Markdown 中保留对应建议的评估原因、依据摘要和来源链接。
- 查询未发布、缺失或旧格式报告，分别核对当日正文空状态、指定版本不存在错误及可读的旧版正文。对不存在与未收藏项提交备注，检查无成功写入的反馈。
