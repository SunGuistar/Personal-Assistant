# 历史晨报与新闻收藏

## 目的与范围

让用户稳定查阅已发布报告并管理想继续关注的新闻。对应 GOALS.md 的「控制与回看」。生成动作及发布前边界见[生成规格](report-generation.md)。

## 场景与规则

- **A 晨报与历史。** 页面提供「晨报正文」「历史晨报」「收藏新闻」同级入口。历史按报告日展示最新已发布版本。失败或停止的运行不替代成功版本。旧版本及其已保存内容继续保留，生成新版本不自动删除旧数据，也不跨日覆盖更新日期的默认晨报。
- **A 收藏。** 在正文或历史报告中设置新闻星标，收藏列表跨报告汇总同一新闻并去重。取消收藏改变收藏状态，不删除新闻及报告快照。
- **A 备注与重点。** 收藏可编辑备注和独立重点，标题与类别只读。红色五角星标记重点并置顶。取消重点仍保留收藏。备注和重点状态可持久读取，备注不进入模型输入或日志正文。
- **C 当前展示。** 默认正文取最新报告日期的最新已发布版本，同日首个发布版本标为主报告。历史弹窗可下载当前版本 Markdown。收藏副本按内容哈希关联，缺哈希时按新闻 ID 处理。取消收藏后隐藏列表项，历史备注和重点保留，再次收藏可恢复。同一报告的速览和正文共用星标，缺少可关联新闻的历史条目不可标记。

## 输入输出与异常

**C 当前对外契约。**

| 接口 | 输入与返回 |
| --- | --- |
| `GET /report` | 可选 `report_date`、整数 `version_no`。返回版本 ID、报告日、日内版本号、主报告标志、标题、正文及可用结构化内容。无参数且无发布结果返回 `null`，指定条件无匹配返回 404。 |
| `GET /history` | 返回 `items`，按日期倒序，每日一条最新已发布版本摘要。无报告时为空列表。 |
| `GET /report/{version_id}/news` | 返回报告关联新闻及当前 `is_important`，没有关联时可为空，版本不存在返回 404。 |
| `PATCH /news/{news_id}/importance` | 必填严格布尔 `is_important` 表示收藏状态，返回更新后的新闻。新闻不存在时返回 404。 |
| `GET /favorites`、`PATCH /favorites/{news_id}` | 列表中每项含新闻标识、标题、类别、链接、收藏状态、`note`、`is_highlighted`。修改仅接收可选字符串 `note`（当前上限 10000，空串清空）和可选严格布尔 `is_highlighted`，未传字段保持原值。未知字段或类型错误返回校验错误，新闻不存在或未收藏时返回 404。 |

收藏加载或保存失败应显示失败结果，以服务端确认的状态为准。空列表与加载失败应可区分。历史兼容展示允许旧报告缺少新结构，用户收藏操作不改写原报告正文。

## 验收

- 同一天包含多个已发布版本及一个失败运行时，历史只列该日最新已发布版本，按旧日期和版本号仍可查到历史正文。重新组装较早日期后，默认正文仍优先较晚报告日期。
- 收藏同一新闻的多个已关联副本，收藏页只有一条。编辑备注、切换重点并刷新，观察备注保留及置顶。取消重点不会取消收藏。
- 查询未发布、缺失或旧格式报告，分别观察合理的空状态、错误或兼容展示。对不存在与未收藏项提交备注，检查无成功写入的反馈。
