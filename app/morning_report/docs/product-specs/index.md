# 今日晨报产品规格

阶段二定稿候选，包含截至 Q90 的最终业务决定，待人工确认阶段验收。规格以用户和 API 调用方能观察到的行为为主。目标、范围和成功条件见 [GOALS.md](../../GOALS.md)，现行业务依据见 [PRD](../../../../Docs/PRD.md)，实现现状见 [模块架构](../../ARCHITECTURE.md)。总体建设范围由 [PLANS.md](../../PLANS.md) 维护。技术方案与任务执行记录分别归后续 Design Docs、ExecPlan。

| GOALS.md 业务目标 | 规格 | 覆盖范围 |
| --- | --- | --- |
| 快速掌握资讯 | [资讯获取与阅读](news.md) | 来源、收录、缺失提示、开篇速览及正文 |
| 回顾与行动 | [个人回顾与行动建议](personal-review.md) | 个人数据、证据边界、回顾、建议与模型异常 |
| 控制生成 | [生成与重新生成](report-generation.md) | 日期、触发、输入复用、发布条件 |
| 回看与收藏 | [历史晨报与新闻收藏](history-and-favorites.md) | 默认报告、历史版本、收藏、备注与重点 |
| 了解进度与停止 | [任务进度与停止](run-progress.md) | 运行状态、错误、停止、重复提交与中断 |

各规格以 **A 已确认规则**、**B 已确认变更**、**C 当前实现**、**D 待确认**标识依据。V3 以 PRD 为业务回归基线。已批准的 B 项覆盖与其冲突的 A 项；C 项仅供兼容性对照。问答编号指本会话的决策记录，同题以用户最终修正为准。已确认的术语见[晨报术语表](../../GLOSSARY.md)。

接口均以 `/api/morning` 为前缀。标为 B 的接口段落定义 V3 可观察行为；具体字段、状态枚举及退役响应由设计阶段确定。业务错误沿用宿主的 `detail.code` 与 `detail.message`。用户可观察的校验、诊断及评估要求随功能列出，评估样本、评分门槛和技术选型留待后续确认。
